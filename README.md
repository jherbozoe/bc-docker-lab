# 🚀 Business Central Docker Lab

![Business Central Docker Lab](docs/images/lab-overview.png)

> Step-by-step guide to create a local Microsoft Dynamics 365 Business Central lab using Docker, BcContainerHelper and Visual Studio Code.

---

## 📖 About

Setting up a local Microsoft Dynamics 365 Business Central environment is one of the first challenges for consultants, developers and anyone starting to learn Business Central.

This repository documents the complete process of creating a local laboratory using Docker and configuring Visual Studio Code to start developing in AL.

The objective is simple:

- Learn Business Central.
- Experiment safely.
- Develop AL extensions.
- Build a reusable development environment.

## 🎯 Learning Path

### 🐳 Part 1 — Docker Lab

- Install Docker Desktop
- Install BcContainerHelper
- Create a Business Central container
- Access the Web Client
- Manage Docker containers

### 💻 Part 2 — Visual Studio Code

- Install Visual Studio Code
- Install the AL Language extension
- Connect VS Code to the container
- Download symbols
- Create your first AL project
- Publish your first extension
